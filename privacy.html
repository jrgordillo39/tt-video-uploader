📌 1. Información que recopilamos

El bot recopila únicamente los datos necesarios para funcionar:

Dato Origen Para qué se usa
ID de usuario de Telegram Telegram Verificar acceso autorizado al bot
Access token de TikTok TikTok OAuth Subir videos en nombre del usuario
Refresh token de TikTok TikTok OAuth Renovar el acceso sin reautenticación
Nombre de usuario de TikTok TikTok API Mostrar la cuenta en el bot
Videos enviados Telegram Subir a TikTok, se eliminan inmediatamente

🚫 2. Lo que NO recopilamos

  • Contraseñas de TikTok o Telegram
  • Datos de navegación o historial
  • Información personal como nombre real, email o teléfono
  • Metadatos de los videos más allá de lo necesario para subirlos
  • Datos de otras cuentas o aplicaciones del dispositivo

💾 3. Almacenamiento de datos

Los tokens de autenticación de TikTok se guardan en un archivo tiktok_tokens.json en el servidor donde corre el bot.

Los videos enviados se descargan temporalmente en memoria del servidor y se eliminan inmediatamente después de ser subidos a TikTok. No se conserva ninguna copia.

🔐 Es tu responsabilidad como operador del bot garantizar que el servidor esté debidamente protegido y que el archivo de tokens no sea accesible públicamente.

🤝 3. Compartición con terceros

Los únicos terceros que reciben datos son:

  • TikTok — recibe los videos y tokens para publicar el contenido. Sujeto a la Política de Privacidad de TikTok.
  • Telegram — procesa los mensajes y archivos enviados al bot. Sujeto a la Política de Privacidad de Telegram.

No se comparten datos con anunciantes, brokers de datos ni ningún otro tercero.

🗑️ 4. Eliminación de datos

Puedes eliminar tus datos en cualquier momento usando el comando /eliminarcuenta en el bot. Esto borra el token de acceso y refresh token de TikTok del servidor.

Para revocar el acceso desde TikTok directamente: TikTok → Perfil → Configuración → Seguridad → Aplicaciones autorizadas.

🔄 5. Cambios en esta política

Esta política puede actualizarse ocasionalmente. Los cambios se reflejarán en la fecha de "Última actualización" al inicio de esta página. El uso continuado del bot implica la aceptación de la política vigente.
