Guía rápida

¿Qué es?

Bot de Telegram que recibe videos y los sube automáticamente a TikTok.

Requisitos

  • Python 3.10+
  • Cuenta de Telegram
  • Cuenta de TikTok Developer

¿Cómo funciona?

  1. Inicia el bot con python bot.py o despliega en Railway/Render.
  2. En Telegram, envía /auth al bot y sigue el proceso de autenticación con TikTok.
  3. Envía cualquier video al bot para subirlo a tu cuenta de TikTok.

Configuración rápida

  • Clona el proyecto y ejecuta pip install -r requirements.txt
  • Configura tus credenciales en el archivo .env
  • Obtén tu Telegram Bot Token con @BotFather
  • Registra tu app en TikTok Developers y copia los datos a .env

Notas importantes

  • La API de TikTok requiere que tu app sea aprobada para uso público.
  • Durante el desarrollo, solo el dueño de la app puede usarla.
  • El tamaño máximo de video por Telegram es 50MB.
